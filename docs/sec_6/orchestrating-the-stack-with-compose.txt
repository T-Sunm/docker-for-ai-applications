That other important addition is a database health check combined with
depends on.
Why do we need a health check?
By itself, depends on only waits for a container to start.
It doesn't guarantee that the service inside the container is ready to accept
connections.
For the database, that difference matters.
The container may be running while the database is still initializing.
The health check solves this problem.
problem.
Compose repeatedly checks the database heartbeat endpoint and waits until it
reports healthy.
Only then the ingestion and query services start.
This prevents startup failures caused by services trying to connect before the
database is ready.
